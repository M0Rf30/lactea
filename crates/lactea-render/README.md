# lactea-render

wgpu backend reproducing the MilkDrop 2 frame pipeline; host-provided device, renders into any texture.

Part of [Lactea](https://github.com/M0Rf30/lactea), a pure-Rust MilkDrop 2/3 and projectM-compatible music visualizer on wgpu. See the repository for documentation and the other crates.
