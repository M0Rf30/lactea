# lactea-abi

Frozen cross-crate contract for lactea: MilkDrop 2 shader constants, binding layout, vertex format, dump layout.

Part of [Lactea](https://github.com/M0Rf30/lactea), a pure-Rust MilkDrop 2 / projectM-compatible music visualizer on wgpu. See the repository for documentation and the other crates.
